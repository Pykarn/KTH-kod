Course layout/Modules

The course learning goals are divided into three main main modules, which are

Module 1 Overview of Database Management Systems
The conceptual data Model/ER
UML and Logical Query Languages
Module 2

Design Theory for Relational Databases, Functional Dependencies
Decomposition of the database, Normalization
Maintaining Referential Integrity/Data Definition Language (DDL) SQL intro Keys and attribute constrains
Module 3

Overview of Relational Algebra
SQL Queries and Relational Algebra (part1) Aggregate Function
The Database language SQL (part2) SQL Join Expressions
Module 4

The Database language SQL (part3) Sub-queries Vs Join
SQL constrains, triggers and views
