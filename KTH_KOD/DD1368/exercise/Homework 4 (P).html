Views:

A view is essentially a stored query. The data from the view does not have to be stored, but the actual query code is saved. This means that the view can be referenced in other queries as a relation instead of having to rewrite complex query code.

 

  1. Views are useful to improve a database, but there are different types of views to consider. Describe the difference between a virtual view and a materialized view.
  2. Give an example of a view that could be used in your social media platform database.
  3. For each statement below, answer whether it is true or false. Motivations are not needed.
  1. A materialized view could contain data that is not up to date.
  2. It takes much longer to create a virtual view than a materialized view.
  3. A query that uses a virtual view always runs much faster than the same query using a materialized view.
  4. A query that uses a materialized view usually runs faster than the same query using a virtual view.
